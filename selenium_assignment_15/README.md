# Assignment 15 - Selenium Automation (Module 23)

This project demonstrates Selenium automation for extracting data from a webpage.

## Website Used
https://quotes.toscrape.com/

## Tasks Done:
- Open webpage using Selenium
- Locate elements
- Extract text (quotes + authors)
- Print extracted data in console

## Technologies Used:
- Python
- Selenium
- Chrome WebDriver (webdriver-manager)

## How to Run

1. Install required modules:
   pip install -r requirements.txt

2. Run the script:
   python main.py

3. Output:
   Displays quotes and authors in terminal.

This folder can be zipped and submitted as assignment.
